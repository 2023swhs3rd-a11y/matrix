# 블룸의 개정 교육목표 분류로 보는 교과탐구활동 추천 매트릭스

Anderson & Krathwohl(2001)의 개정 블룸 분류에서 **지식 차원(4)** × **인지 과정 차원(6)** 을 교차한 24칸에 탐구활동을 추천합니다. **2022 개정 교육과정** 고1 공통과목 14개(과학탐구실험 포함)와 2·3학년 일반선택·진로선택·융합선택 과목은 성취기준을 칸에 배치하고 과목별 활동을 따로 정리했습니다.

## 두 축

| 인지 과정 | 뜻 | 하위 과정 |
|---|---|---|
| 1. 기억 (Remember) | 장기기억에서 관련 지식을 인출하기 | 재인하기 · 회상하기 |
| 2. 이해 (Understand) | 말·글·그림으로 된 메시지의 의미 구성하기 | 해석 · 예시 · 분류 · 요약 · 추론 · 비교 · 설명 |
| 3. 적용 (Apply) | 주어진 상황에서 절차를 수행하거나 사용하기 | 실행하기 · 시행하기 |
| 4. 분석 (Analyze) | 자료를 구성 요소로 나누고 관계와 구조 파악하기 | 구별하기 · 조직하기 · 귀속하기 |
| 5. 평가 (Evaluate) | 준거와 기준에 비추어 판단하기 | 점검하기 · 비판하기 |
| 6. 창안 (Create) | 요소를 엮어 새롭고 일관된 전체 만들기 | 생성하기 · 계획하기 · 산출하기 |

| 지식 차원 | 하위 유형 |
|---|---|
| A. 사실적 지식 (Factual) | 용어, 구체적 사실과 요소 |
| B. 개념적 지식 (Conceptual) | 분류·범주, 원리·일반화, 이론·모형·구조 |
| C. 절차적 지식 (Procedural) | 기능·알고리즘, 기법·방법, 절차 사용 시기의 판단 준거 |
| D. 메타인지 지식 (Metacognitive) | 전략적 지식, 인지 과제에 대한 지식, 자기 지식 |

## 탐구 경로 예시

- **입문형 탐구**: A1(사실적·기억) → A2(사실적·이해) → B2(개념적·이해) → C3(절차적·적용)  
  용어와 사실을 익히고 개념을 이해한 뒤 정해진 절차로 탐구를 수행합니다. 탐구 경험이 적은 학생에게 맞습니다.
- **심화형 탐구**: B2(개념적·이해) → B4(개념적·분석) → C4(절차적·분석) → C6(절차적·창안)  
  개념 구조를 분석하고 방법을 비교한 뒤 자신의 탐구를 설계합니다. 주제 탐구 보고서나 과제 연구에 맞습니다.
- **성찰형 탐구**: C3(절차적·적용) → C5(절차적·평가) → D4(메타인지·분석) → D6(메타인지·창안)  
  탐구를 수행하고 과정을 평가한 뒤 자신의 탐구 방식을 돌아보고 다음 계획을 세웁니다. 학기말 정리 활동에 맞습니다.

## 활용 안내

1. **성취기준 찾기:** 과목별 문서에서 수업할 성취기준의 칸을 확인합니다. 예: “이차함수의 최대, 최소를 탐구하고, 이를 실생활과 연결하여…” → 개념적 지식 × 적용(B3).
2. **활동 고르기:** 그 칸의 과목별 활동을 고르거나, 전 과목 공통 활동을 과목 내용에 맞게 바꿉니다.
3. **단계 배치:** 주된 칸의 왼쪽이나 위쪽 칸에서 시작해 2~4칸을 이어 탐구 경로를 만듭니다.
4. **평가 정렬:** 주된 칸의 활동 결과물을 수행평가 대상으로 삼아 성취기준, 활동, 평가를 같은 칸에 맞춥니다.
