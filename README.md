# 블룸의 개정 교육목표 분류로 보는 교과탐구활동 추천 매트릭스

Anderson & Krathwohl(2001)의 개정 블룸 분류에서 **지식 차원(4)** × **인지 과정 차원(6)** 을 교차한 24칸에 탐구활동을 추천합니다. **2022 개정 교육과정** 고1 공통과목 14개(과학탐구실험 포함)와 2·3학년 일반선택·진로선택·융합선택 과목은 성취기준을 칸에 배치하고 과목별 활동을 따로 정리했습니다.

## 두 축

| 인지 과정 | 뜻 | 하위 과정 |
|---|---|---|
| 1. 기억 (Remember) | 장기기억에서 관련 지식을 인출하기 | 재인하기 · 회상하기 |
| 2. 이해 (Understand) | 말·글·그림으로 된 메시지의 의미 구성하기 | 해석하기 · 예시하기 · 분류하기 · 요약하기 · 추론하기 · 비교하기 · 설명하기 |
| 3. 적용 (Apply) | 주어진 상황에서 절차를 수행하거나 사용하기 | 실행하기 · 시행하기 |
| 4. 분석 (Analyze) | 자료를 구성 요소로 나누고 관계와 구조 파악하기 | 구별하기 · 조직하기 · 귀속하기 |
| 5. 평가 (Evaluate) | 준거와 기준에 비추어 판단하기 | 점검하기 · 비판하기 |
| 6. 창안 (Create) | 요소를 엮어 새롭고 일관된 전체 만들기 | 생성하기 · 계획하기 · 산출하기 |

| 지식 차원 | 하위 유형 |
|---|---|
| A. 사실적 지식 (Factual) | 용어, 구체적 사실과 요소 |
| B. 개념적 지식 (Conceptual) | 분류·범주, 원리·일반화, 이론·모형·구조 |
| C. 절차적 지식 (Procedural) | 기능·알고리즘, 기법·방법, 절차 사용 시기의 판단 준거 |
| D. 메타인지 지식 (Metacognitive) | 전략적 지식, 인지 과제에 대한 지식, 자기 지식 |

## 탐구 경로 예시

- **입문형 탐구**: A1(사실적·기억) → A2(사실적·이해) → B2(개념적·이해) → C3(절차적·적용)  
  용어와 사실을 익히고 개념을 이해한 뒤 정해진 절차로 탐구를 수행합니다. 탐구 경험이 적은 학생에게 맞습니다.
- **심화형 탐구**: B2(개념적·이해) → B4(개념적·분석) → C4(절차적·분석) → C6(절차적·창안)  
  개념 구조를 분석하고 방법을 비교한 뒤 자신의 탐구를 설계합니다. 주제 탐구 보고서나 과제 연구에 맞습니다.
- **성찰형 탐구**: C3(절차적·적용) → C5(절차적·평가) → D4(메타인지·분석) → D6(메타인지·창안)  
  탐구를 수행하고 과정을 평가한 뒤 자신의 탐구 방식을 돌아보고 다음 계획을 세웁니다. 학기말 정리 활동에 맞습니다.

## 과목 융합 탐구

두 과목의 성취기준이 매트릭스의 어느 칸에서 만나는지에 따라 융합 탐구의 유형을 나눴습니다.

### 개념 연결형

- **매트릭스 위치:** 두 과목 모두 개념적 지식(B행) × 이해·분석(B2·B4)
- **특징:** 한 과목의 개념이 다른 과목의 현상을 설명하는 언어가 되는 탐구입니다. 새 결과물을 만들기보다 “이 개념으로 저 현상이 왜 그런지 설명된다”는 연결을 찾는 데 목적이 있습니다.
- **시작하기:** 두 과목 교과서에서 같은 현상이 나오는 쪽을 찾아 “이 과목의 개념으로 저 과목의 현상을 설명할 수 있을까?”라고 질문해 보세요.

**사인함수로 보는 빛과 소리의 간섭** (대수 [12대수02-02] B2 + 물리학 [12물리03-01] B2)

- 탐구 질문: 두 파동이 겹칠 때 밝아지거나 조용해지는 현상을 사인함수의 합으로 설명할 수 있을까?
- 공학 도구로 y=sin x와 y=sin(x+a)를 그리고 a를 0에서 π까지 바꾸며 두 함수의 합을 관찰한다
- 위상차가 0일 때 진폭이 두 배가 되고 π일 때 0이 되는 것을 보강 간섭과 상쇄 간섭으로 연결한다
- 비눗방울의 무지갯빛과 노이즈 캔슬링 이어폰을 같은 원리로 설명하는 자료를 만든다
- 산출물: 사인함수 합 그래프와 간섭 현상 설명 자료
- 더 탐구해 볼 내용: 진동수가 조금 다른 두 소리를 겹치면 생기는 맥놀이를 그래프로 확인하기 / 복잡한 소리를 여러 사인함수의 합으로 나타내는 푸리에 분석이 음성 인식에 쓰이는 방식 조사하기

**1930년대 소설로 읽는 식민지 도시의 일상** (문학 [12문학01-04] B4 + 한국사2 [10한사2-01-04] B2)

- 세 정책이 가격과 유인을 통해 배출을 줄이는 원리를 경제 개념으로 정리한다
- 효율성(감축 비용), 형평성(저소득층 부담), 실현 가능성 기준표를 만든다
- 우리나라 배출권 거래제와 해외 탄소세 사례 자료로 각 정책을 평가한다
- 산출물: 정책 평가표와 입장문
- 더 탐구해 볼 내용: 탄소세 수입을 국민에게 나누어 주는 탄소 배당이 형평성 문제를 줄이는지 조사하기 / 유럽 연합의 탄소 국경 조정 제도가 우리 수출 산업에 미칠 영향 분석하기

**유전자 가위 치료 기사, 어디까지 믿을까** (매체 의사소통 [12매의01-04] B5 + 생물의 유전 [12유전03-02] B5)

- 탐구 질문: “유전병 완치 시대”라는 기사 제목은 실제 연구 결과를 정확하게 전하고 있을까?
- 2023년 승인된 겸상 적혈구 빈혈증 유전자 편집 치료제를 다룬 기사들을 모은다
- 규제 기관 발표와 원자료에서 대상 환자, 효과, 한계, 비용을 확인한다
- 기사 제목과 본문이 연구 결과를 과장하거나 빠뜨린 부분을 신뢰성 기준으로 평가한다
- 산출물: 과학 기사 신뢰성 평가표와 고쳐 쓴 기사 제목
- 더 탐구해 볼 내용: 임상 시험 단계와 승인 절차 용어를 정리해 기사 읽기 도구 만들기 / 치료비와 접근성 문제를 생명공학의 사회적 책임과 연결해 토론하기

### 창안·문제 해결형

- **매트릭스 위치:** 창안하기(B6·C6) 칸
- **특징:** 두 과목의 지식과 방법을 모아 실제로 쓰일 결과물(프로그램, 캠페인, 설계안)을 만드는 탐구입니다. 누가 사용할지 정하고, 결과물이 그 사람에게 효과가 있었는지 확인하는 단계까지 가야 합니다.
- **시작하기:** “이 결과물을 누가, 어디에서 쓸까?”를 먼저 정하면 두 과목에서 각각 무엇을 가져와야 할지 분명해집니다.

**화산 지형으로 짜는 지오투어리즘 코스** (여행지리 [12여지02-04] B6 + 지구시스템과학 [12지시01-04] B4)

- 탐구 질문: 한탄강 지질공원의 현무암 협곡을 중학생이 즐겁게 배우는 하루 여행 코스로 만들 수 있을까?
- 주상 절리, 베개 용암 같은 지오사이트에서 화산 활동과 암석 형성 과정을 조사한다
- 지오사이트의 과학적 가치와 경관 가치를 기준으로 코스를 고르고 동선을 짠다
- 현장 해설 카드와 관찰 활동지를 만들고 지역 주민 해설사·상권과의 연계를 제안한다
- 산출물: 지오투어리즘 코스 지도와 해설 카드
- 더 탐구해 볼 내용: 관광객이 늘 때 지오사이트를 보전하는 방법과 수용 인원 조사하기 / 휠체어 이용자도 갈 수 있는 무장애 코스로 바꾸어 설계하기

**설문 결과로 만드는 청소년 수면 캠페인** (매체 의사소통 [12매의01-06] C6 + 사회문제 탐구 [12사탐04-03] B6)

- 탐구 질문: 우리 학교 학생들의 수면 부족 원인을 자료로 밝히고, 그 원인에 맞춘 캠페인 영상을 만들 수 있을까?
- 전교생 설문으로 수면 시간과 취침 전 스마트폰 사용 실태를 조사하고 분석한다
- 분석 결과에서 가장 큰 원인을 골라 해결 방안과 핵심 메시지를 정한다
- 학생들이 주로 쓰는 매체 형식으로 1분 영상을 제작해 공유한다
- 산출물: 실태 분석 보고서와 캠페인 영상
- 더 탐구해 볼 내용: 영상 시청 전후 취침 시간 변화를 다시 조사해 효과 확인하기 / 결과를 학교 생활 규정 개선 제안서로 확장하기

### 성찰 전이형

- **매트릭스 위치:** 메타인지 지식(D행) × 분석·평가(D3·D5)
- **특징:** 탐구 내용보다 탐구하는 방식 자체를 돌아보는 탐구입니다. 한 과목에서 익힌 점검 기준(통계의 타당성, 연구 윤리, 글쓰기 점검 등)을 다른 과목의 탐구에 옮겨 써서 내 탐구 습관을 고칩니다.
- **시작하기:** 탐구를 마친 뒤 “다른 과목의 기준으로 보면 내 탐구의 약점은 무엇일까?”라고 물어보세요. 다음 탐구 계획서에 고친 점을 적으면 완성됩니다.

**설문 탐구를 통계와 연구 윤리 두 눈으로 회고하기** (실용 통계 [12실통04-02] D5 + 사회문제 탐구 [12사탐01-04] D3)

- 탐구 질문: 내가 한 설문 탐구의 결론은 통계적으로 믿을 만했고, 참여자를 존중하며 진행되었을까?
- 표본 선정, 문항, 응답률, 분석 방법을 통계적 타당성 기준으로 점검한다
- 동의 절차, 개인 정보 처리, 결과 공유를 연구 윤리 기준으로 점검한다
- 두 점검표에서 찾은 문제를 다음 탐구 계획서에 고쳐 반영한다
- 산출물: 두 관점 점검표와 고친 탐구 계획서
- 더 탐구해 볼 내용: 표본 편향과 동의 절차가 응답 결과에 준 영향을 비교해 보기 / 다른 과목의 실험 탐구에도 같은 점검표를 적용해 보기


## 활용 안내

1. **성취기준 찾기:** 과목별 문서에서 수업할 성취기준의 칸을 확인합니다. 예: “이차함수의 최대, 최소를 탐구하고, 이를 실생활과 연결하여…” → 개념적 지식 × 적용(B3).
2. **활동 고르기:** 그 칸의 과목별 활동을 고르거나, 전 과목 공통 활동을 과목 내용에 맞게 바꿉니다.
3. **단계 배치:** 주된 칸의 왼쪽이나 위쪽 칸에서 시작해 2~4칸을 이어 탐구 경로를 만듭니다.
4. **평가 정렬:** 주된 칸의 활동 결과물을 수행평가 대상으로 삼아 성취기준, 활동, 평가를 같은 칸에 맞춥니다.
