BLOOM’S REVISED TAXONOMY · ANDERSON & KRATHWOHL (2001)

블룸의 개정 교육목표 분류로 보는 학생 탐구활동 추천 매트릭스

지식 차원 4가지와 인지 과정 차원 6가지를 교차한 24칸에 칸마다 추천 탐구활동과 산출물을 넣은 기본형입니다. 칸 번호(A1~D6)로 활동을 지정하고, 아래 탐구 경로를 눌러 활동 순서를 표에서 확인할 수 있습니다.

A. Factual사실적 지식용어, 구체적 사실과 요소 A1
  • 탐구 주제의 핵심 용어 플래시카드 만들어 짝 퀴즈
  • 관련 사건·수치를 연표나 사실 목록으로 정리
산출물 용어 카드, 사실 목록
 A2
  • 핵심 용어를 자기 말로 풀어 쓰고 예를 덧붙이기
  • 기사·그래프에서 사실을 찾아 세 줄로 요약
산출물 용어 풀이 노트, 자료 요약문
 A3
  • 관찰·측정·설문으로 사실 자료를 모아 기록표 작성
  • 정해진 단위와 기호로 자료를 정리해 표 만들기
산출물 관찰·측정 기록표
 A4
  • 같은 주제를 다룬 여러 출처의 사실을 대조해 일치·불일치 표시
  • 자료 속 문장을 사실과 의견으로 구분
산출물 출처 대조표
 A5
  • 출처·작성자·날짜를 점검하는 팩트체크 활동
  • 수집한 수치의 정확성을 원자료와 다시 맞춰 보기
산출물 팩트체크 보고서
 A6
  • 모은 사실로 인포그래픽이나 카드뉴스 제작
  • 학급 공동 용어집이나 주제 데이터베이스 구축
산출물 인포그래픽, 용어집
B. Conceptual개념적 지식분류·범주, 원리·일반화, 이론·모형·구조 B1
  • 교과 핵심 개념의 정의와 원리 회상하기
  • 개념 이름과 정의 짝 맞추기 게임
산출물 개념 정의 목록
 B2
  • 개념도(마인드맵)로 개념 간 관계 그리기
  • 개념의 예시와 반례, 비유 만들기
  • 원리로 일상 현상을 설명하기
산출물 개념도, 설명 글
 B3
  • 배운 원리를 새로운 상황의 문제에 적용해 풀기
  • 모형을 사용해 현상의 결과 예측하기
산출물 적용 문제 풀이, 예측표
 B4
  • 벤 다이어그램이나 인과 지도로 개념 구조 분석
  • 이론이 깔고 있는 가정과 한계 찾기
산출물 인과 지도, 비교 다이어그램
 B5
  • 두 이론이나 모형을 설명력 기준으로 비교 평가
  • 근거를 들어 주장하는 찬반 토론
산출물 비교 평가표, 토론 논증문
 B6
  • 새로운 분류 체계나 설명 모형 제안
  • 개념을 엮어 검증 가능한 가설 세우기
산출물 자작 모형, 가설 진술문
C. Procedural절차적 지식기능·알고리즘, 기법·방법, 절차 사용 시기의 판단 준거 C1
  • 실험·조사 절차의 순서 회상하기
  • 안전 수칙과 도구 사용법 체크리스트 작성
산출물 절차 카드, 안전 체크리스트
 C2
  • 절차의 각 단계가 왜 필요한지 설명하기
  • 탐구 절차를 순서도로 나타내기
산출물 순서도, 절차 해설
 C3
  • 표준 실험이나 조사 절차를 그대로 수행
  • 통계·코딩 도구로 자료 처리하기
  • 설문이나 인터뷰 실시
산출물 실험 결과, 자료 처리 결과
 C4
  • 여러 탐구 방법의 장단점 비교 분석
  • 실험 설계에서 독립·종속·통제 변인 찾기
산출물 방법 비교표, 변인 분석표
 C5
  • 실험 과정의 오차 원인과 타당도 평가
  • 동료의 탐구 보고서를 루브릭으로 검토
산출물 오차 분석, 동료 검토지
 C6
  • 탐구 질문에 맞는 실험·조사를 직접 설계
  • 새로운 측정 도구나 조사 프로토콜 개발
산출물 탐구 계획서, 자작 도구

  • 과제 유형별로 효과가 있던 전략 떠올리기
산출물 나의 전략 목록
 D2

  • 어떤 전략이 왜 효과적이었는지 설명
산출물 탐구 일지
 D3
  • 과제에 맞는 전략을 골라 실제로 써 보기
  • 자기 질문 체크리스트로 탐구 중간 점검
산출물 전략 실행 기록
 D4
  • 나의 탐구 과정을 단계별로 돌아보기
  • 막히거나 실패한 지점의 원인 분석
산출물 탐구 회고록
 D5
  • 루브릭으로 자기평가와 동료평가 하기
  • 사용한 전략이 목표 달성에 효과적이었는지 판단
산출물 자기평가지
 D6
  • 다음 탐구를 위한 개인 학습 계획 세우기
  • 탐구 포트폴리오와 성장 로드맵 설계
산출물 성장 계획서, 포트폴리오

오른쪽으로 갈수록 고차원 사고(인지 과정), 아래로 갈수록 추상적인 지식입니다. 칸 색이 진할수록 인지 부담이 큰 활동입니다.

탐구 경로 예시

한 학기 탐구를 몇 칸의 순서로 묶은 예시입니다. 경로를 누르면 표에 해당 칸이 표시됩니다.

활용 안내

  1. 목표 진술: 성취기준을 “명사(지식 차원) + 동사(인지 과정)”로 나누면 해당 칸이 정해집니다. 예: “광합성의 원리를 설명할 수 있다” → 개념적 지식 × 이해(B2).
  2. 활동 선택: 칸의 추천 활동 중 하나를 고르고 교과 주제에 맞게 바꿉니다. 같은 칸이면 교과가 달라도 활동 형태는 그대로 쓸 수 있습니다.
  3. 단계 배치: 왼쪽 위(A1)에서 오른쪽 아래(D6) 방향으로 2~4칸을 이어 탐구 경로를 만듭니다. 꼭 한 칸씩 순서대로 갈 필요는 없습니다.
  4. 평가 정렬: 산출물 칸에 적힌 결과물을 평가 대상으로 삼으면 목표, 활동, 평가가 같은 칸에 맞춰집니다.
