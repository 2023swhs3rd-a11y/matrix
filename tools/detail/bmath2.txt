T 집합·명제 기호 읽기
Q 기호 ∈와 ⊂는 무엇이 다를까?
S 교과서에서 ∈, ⊂, ∪, ∩, ~p 기호를 찾아 뜻을 적는다 ;; 기호마다 읽는 법과 예를 붙인다 ;; 헷갈리는 기호 쌍을 골라 차이를 설명한다
O 집합·명제 기호표
R ∈, ⊂, ∪, ∩, ~p의 읽는 법과 뜻을 표로 정리함. 1∈{1, 2}와 {1}⊂{1, 2}를 예로 들어 원소와 집합의 관계와 집합 사이의 관계를 구별해 설명함.

@A3
T 학교 지도에서 거리 계산
Q 지도에서 두 건물 사이 직선거리는 어떻게 구할까?
S 학교 배치도에 좌표축을 정한다 ;; 본관과 체육관의 좌표를 읽는다 ;; 두 점 사이의 거리 공식으로 거리를 구하고 실제 걸음 수와 비교한다
O 좌표 지도와 거리 계산표
R 학교 배치도에 1칸을 10m로 하는 좌표를 정하고 본관 (0, 0)과 체육관 (6, 8)의 거리를 공식으로 구해 100m를 얻음. 실제로 걸어 잰 거리와 비교해 건물 사이에 길이 꺾여 있어 걷는 거리가 더 길다는 점을 설명함.

@B2
T 집합·함수·명제의 뜻 설명
Q 우리 반 동아리 명단, 자판기, 광고 문구 속에 집합, 함수, 명제가 숨어 있을까?
S 동아리 명단을 원소나열법과 조건제시법으로 쓴다 ;; 자판기 버튼과 음료의 대응으로 함수의 조건을 확인한다 ;; 일상 문장 가운데 참과 거짓을 가릴 수 있는 문장을 고른다
O 개념 설명 노트
R 동아리 명단을 두 가지 방법으로 나타내고, 자판기 버튼 하나에 음료가 하나씩 나오면 함수이지만 한 버튼에 두 음료가 나오면 함수가 아니라는 점을 설명함. 두 직선의 기울기를 비교해 기울기가 같으면 평행, 곱이 -1이면 수직임을 그림으로 정리함.

@B3
T 지도 앱과 거울 속 이동
Q 지도 앱에서 화면을 옮기는 것과 거울에 비친 모습은 어떤 이동일까?
S 지도 앱 화면 이동을 좌표의 평행이동으로 적는다 ;; 데칼코마니 그림의 대응점 좌표를 읽어 대칭이동 규칙을 찾는다 ;; 서로 수직인 두 길을 직선의 방정식으로 나타낸다
O 이동 규칙 정리표
R 지도 앱에서 화면을 오른쪽으로 3칸, 위로 2칸 옮기면 점 (x, y)가 (x+3, y+2)로 바뀜을 평행이동으로 나타냄. 데칼코마니 그림의 대응점을 읽어 y축 대칭은 (x, y)가 (-x, y)로 바뀌는 것임을 찾고, 교문 앞 수직인 두 길의 직선 방정식을 구함.

@B4
T 그래프로 판단하고 비교하기
Q y=k/x에서 k가 커지면 그래프는 어떻게 바뀔까?
S 원의 중심과 직선 사이 거리를 반지름과 비교한다 ;; 공학 도구로 k 값을 바꾸며 y=k/x 그래프를 그린다 ;; y=√x와 y=x²(x≥0) 그래프를 같은 좌표평면에 그려 비교한다
O 그래프 비교 분석표
R 원의 중심과 직선 사이 거리가 반지름보다 작으면 두 점에서 만난다는 기준으로 위치 관계를 판단함. 공학 도구로 k를 1, 2, 4로 바꾸어 y=k/x 그래프가 원점에서 멀어지는 것을 확인하고, y=√x가 y=x²(x≥0)과 직선 y=x에 대해 대칭이라는 점을 찾아 역함수와 이어지는 추가 탐구 질문을 세움.

@B5
T 광고 문구의 역과 대우
Q '이 운동화를 신으면 빨리 달린다'의 대우도 참일까?
S 광고 문구를 'p이면 q이다' 꼴로 바꾼다 ;; 역과 대우를 만든다 ;; 각각 참과 거짓을 판단하고 반례를 찾는다
O 명제 판단표
R 광고 문구 다섯 개를 'p이면 q이다' 꼴로 바꾸고 역과 대우를 만들어 참과 거짓을 판단함. 원래 명제와 대우는 참과 거짓이 같지만 역은 다를 수 있음을 반례로 보이고, 광고가 역을 참인 것처럼 쓰는 경우를 비판함.

@B6
T 대칭이동으로 만드는 학급 로고
Q 대칭이동을 쓰면 균형 잡힌 로고를 만들 수 있을까?
S 로고의 기본 도형을 좌표평면에 그린다 ;; x축, y축, 원점, y=x 대칭이동을 적용한다 ;; 대칭 방법별 느낌을 비교해 최종 로고를 고른다
O 학급 로고 시안
R 기본 도형의 꼭짓점 좌표를 정하고 y축 대칭과 원점 대칭을 적용해 학급 로고 시안 두 개를 만듦. 미술 시간에 배운 대칭 구도 원리와 연결해 y=x 대칭이 대각선 방향의 움직임을 준다는 점을 설명함.

@C2
T 섭씨-화씨 역함수 구하기
Q 섭씨를 화씨로 바꾸는 식이 있다면 거꾸로 바꾸는 식은 어떻게 만들까?
S 섭씨를 화씨로 바꾸는 식 F=1.8C+32를 확인한다 ;; x와 y를 바꾸고 y에 대해 정리하는 순서를 적는다 ;; 두 식에 같은 값을 넣어 원래 값으로 돌아오는지 확인한다
O 역함수 구하는 순서도
R F=1.8C+32에서 C에 대해 정리해 C=(F-32)/1.8을 구하고, 역함수를 구하는 순서를 순서도로 설명함. 30℃가 86℉가 되고 다시 30℃로 돌아오는 것을 계산해 역함수의 뜻을 확인함.

@C3
T 방정식·집합·합성함수 계산
Q 할인 뒤에 세금을 붙이는 것과 세금 뒤에 할인하는 것은 값이 같을까?
S 두 점을 지나는 직선과 중심·반지름이 주어진 원의 방정식을 구해 그린다 ;; 학급 설문 결과를 벤 다이어그램으로 정리한다 ;; 할인 함수와 세금 함수를 합성해 순서를 바꿔 계산한다
O 계산 기록지와 벤 다이어그램
R 학급 설문에서 운동과 독서를 좋아하는 학생 수를 벤 다이어그램으로 정리해 합집합과 교집합의 원소 수를 구함. 10% 할인 함수와 10% 세금 함수의 합성을 순서를 바꿔 계산해 이 경우 값이 같지만 정액 할인이면 달라진다는 점을 찾아 후속 탐구로 이어 가기로 함.
