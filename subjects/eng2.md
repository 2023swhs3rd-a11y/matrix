# 영어Ⅱ 탐구활동 추천 매트릭스

2022 개정 교육과정 영어Ⅱ 성취기준 17개를 개정 블룸 분류 칸에 배치하고, 칸마다 과목에 맞춘 탐구활동을 정리했습니다. [전체 README로 돌아가기](../README.md)

## 성취기준 배치

주된 칸은 굵게 표시했습니다.

| 코드 | 성취기준 | 칸 |
|---|---|---|
| [12영Ⅱ-01-01] | 다양한 주제에 대한 말이나 글의 세부 정보를 파악한다. | **A2** 사실적·이해 |
| [12영Ⅱ-01-02] | 말이나 글의 주제나 요지를 파악한다. | **B2** 개념적·이해 |
| [12영Ⅱ-01-03] | 말이나 글에 나타난 화자, 필자, 인물 등의 심정이나 의도를 추론한다. | **B2** 개념적·이해 |
| [12영Ⅱ-01-04] | 말이나 글에서 일이나 사건의 논리적 관계를 추론한다. | **B4** 개념적·분석 |
| [12영Ⅱ-01-05] | 말이나 글의 맥락을 바탕으로 함축된 의미를 추론한다. | **B2** 개념적·이해 |
| [12영Ⅱ-01-06] | 다양한 유형의 말이나 글의 전개 방식이나 구조를 파악한다. | **B4** 개념적·분석 |
| [12영Ⅱ-01-07] | 적절한 전략을 적용하여 다양한 매체 자료의 말이나 글을 이해한다. | **D3** 메타인지·적용 |
| [12영Ⅱ-01-08] | 다양한 문화와 관점에 대해 포용하고 공감하는 태도를 가진다. | **B4** 개념적·분석 |
| [12영Ⅱ-02-01] | 다양한 주제에 대한 사실적 정보를 말이나 글로 설명한다. | **A2** 사실적·이해 |
| [12영Ⅱ-02-02] | 지식과 경험을 활용하여 자신의 감상이나 느낌을 표현한다. | **B6** 개념적·창안 |
| [12영Ⅱ-02-03] | 상대방을 배려하고 존중하는 태도로 자신의 의견이나 주장을 제시한다. | **C6** 절차적·창안 |
| [12영Ⅱ-02-04] | 다양한 주제에 대해 듣거나 읽은 내용을 재구성하여 요약한다. | **B2** 개념적·이해, B6 개념적·창안 |
| [12영Ⅱ-02-05] | 적절한 전략을 활용하여 논리적으로 대상을 설득한다. | **D3** 메타인지·적용, C6 절차적·창안 |
| [12영Ⅱ-02-06] | 자기소개서, 이력서, 보고서 등의 서식을 목적에 맞게 작성한다. | **C3** 절차적·적용 |
| [12영Ⅱ-02-07] | 글을 쓰는 과정에서 글의 내용과 형식을 점검하고 쓰기 윤리를 준수하여 고쳐 쓴다. | **C5** 절차적·평가 |
| [12영Ⅱ-02-08] | 다양한 매체를 활용하여 정보를 창의적이고 효과적으로 전달한다. | **A6** 사실적·창안 |
| [12영Ⅱ-02-09] | 원활한 의견 교환을 위해 협력적이고 능동적으로 의사소통 활동에 참여한다. | **C3** 절차적·적용 |

## 과목별 활동 매트릭스

활동 뒤 괄호는 관련 성취기준 코드 뒷자리, 칸 끝의 “성취기준”은 그 칸에 배치된 성취기준입니다.

| 지식 \ 인지 | 1. 기억 | 2. 이해 | 3. 적용 | 4. 분석 | 5. 평가 | 6. 창안 |
|---|---|---|---|---|---|---|
| **A. 사실적 지식** | `A1` • 진로·학문 분야별 영어 어휘 목록 | `A2` • 다양한 주제 지문의 세부 정보 파악 (01-01)<br>• 사실 정보 영어 설명 (02-01)<br>**성취기준:** 01-01, 02-01 | `A3` • 관심 분야 영어 자료 수집과 출처 기록 (02-01) | `A4` • 주장과 근거 문장 구별 (02-05) | `A5` • 영어 자료 출처 신뢰성 점검 | `A6` • 매체 활용 영어 정보 발표 (02-08)<br>**성취기준:** 02-08 |
| **B. 개념적 지식** | `B1` • 글 유형별 전개 방식 회상 (01-06) | `B2` • 주제·요지·함축 의미 추론 (01-02, 01-05)<br>• 인물 심정과 의도 추론 (01-03)<br>**성취기준:** 01-02, 01-03, 01-05, 02-04 | `B3` • 논리적 관계를 단서로 빈칸 추론 (01-04) | `B4` • 다양한 유형 글의 구조 분석 (01-06)<br>• 문화와 관점 차이 분석 (01-08)<br>**성취기준:** 01-04, 01-06, 01-08 | `B5` • 두 글의 주장 설득력 평가 (02-05) | `B6` • 읽은 내용을 재구성한 요약과 감상문 (02-02, 02-04)<br>**성취기준:** 02-02, 02-04 |
| **C. 절차적 지식** | `C1` • 자기소개서·보고서 서식 요소 회상 (02-06) | `C2` • 설득하는 글의 구성 단계 설명 (02-05) | `C3` • 목적에 맞는 자기소개서·보고서 작성 (02-06)<br>• 영어 토의 참여 (02-09)<br>**성취기준:** 02-06, 02-09 | `C4` • 설득 에세이의 논증 구조 분석 (02-05) | `C5` • 내용·형식 점검하고 쓰기 윤리 지켜 고쳐 쓰기 (02-07)<br>**성취기준:** 02-07 | `C6` • 배려하는 태도로 주장 제시하는 영어 토론 (02-03, 02-05)<br>**성취기준:** 02-03, 02-05 |
| **D. 메타인지 지식** | `D1` • 나의 읽기·쓰기 전략 목록 (01-07) | `D2` • 영어 설득 글이 어려운 이유 설명 | `D3` • 매체 자료 이해 전략 적용 (01-07)<br>• 설득 전략 골라 활용 (02-05)<br>**성취기준:** 01-07, 02-05 | `D4` • 쓴 글 포트폴리오 회고 (02-07) | `D5` • 쓰기 자기평가 루브릭 (02-07) | `D6` • 진로 연계 영어 학습 계획 |
