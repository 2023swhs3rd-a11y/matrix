# 삶과 종교 탐구활동 추천 매트릭스

2022 개정 교육과정 삶과 종교 성취기준 14개를 개정 블룸 분류 칸에 배치하고, 칸마다 과목에 맞춘 탐구활동을 정리했습니다. [전체 README로 돌아가기](../README.md)

## 성취기준 배치

주된 칸은 굵게 표시했습니다.

| 코드 | 성취기준 | 칸 |
|---|---|---|
| [12삶종01-01] | 다양한 인간의 삶에서 종교의 의미와 역할, 종교성과 영성을 이해한다. | **B2** 개념적·이해 |
| [12삶종01-02] | 종교적인 질문을 통해 청소년 시기에 경험하는 삶의 다양한 문제를 탐색한다. | **D4** 메타인지·분석 |
| [12삶종01-03] | 사회적 문제를 종교적 관점으로 바라보고 종교적 통찰과 지혜를 삶과 일상에 적용하고 실천하는 태도를 갖는다. | **B3** 개념적·적용 |
| [12삶종02-01] | 다양한 종교의 기원과 창시자, 역사적 형성 과정을 탐색한다. | **A2** 사실적·이해 |
| [12삶종02-02] | 다양한 종교의 경전과 전통, 교리와 문화, 공동체와 의례를 비교하여 특징을 분석한다. | **B4** 개념적·분석 |
| [12삶종02-03] | 다양한 종교의 세계관과 윤리적 가치를 인식하고, 존중하는 태도를 기른다. | **B2** 개념적·이해 |
| [12삶종03-01] | 일상생활과 통과 의례에 담긴 종교 문화유산을 이해하고 삶의 과정을 통과 의례를 중심으로 성찰한다. | **A2** 사실적·이해, D5 메타인지·평가 |
| [12삶종03-02] | 음악, 미술, 건축, 문학 영역에서 종교적 문화유산을 탐구하고 아름다움을 감상한다. | **B5** 개념적·평가 |
| [12삶종03-03] | 다양한 종교 문화유산을 분야별로 분류하고 특징을 분석하며, 인류의 문화유산으로 존중하는 마음을 갖는다. | **A4** 사실적·분석 |
| [12삶종03-04] | 다양한 분야의 종교 문화유산을 감상하고, 이를 창의적이고 융합적으로 표현한다. | **B6** 개념적·창안 |
| [12삶종04-01] | 다양한 종교의 핵심 가치와 덕목을 탐구하고 포용성과 상호 존중이라는 공통점을 발견한다. | **B4** 개념적·분석 |
| [12삶종04-02] | 종교가 추구하는 공동의 선(善)을 이해하고, 변화하는 사회에 필요한 시민 의식과 태도를 갖는다. | **B2** 개념적·이해 |
| [12삶종04-03] | 현대 사회의 문제에 대해 종교계가 제시하는 여러 해법을 이해함으로써 공동체의 문제해결에 필요한 연대감과 책임감을 기른다. | **B3** 개념적·적용 |
| [12삶종04-04] | 종교와 유사 종교를 구분할 수 있는 관점을 기른다. | **B5** 개념적·평가 |

## 과목별 활동 매트릭스

활동 뒤 괄호는 관련 성취기준 코드 뒷자리, 칸 끝의 “성취기준”은 그 칸에 배치된 성취기준입니다. 성취기준이 없는 칸(—)은 이 과목의 교육목표에 해당하지 않아 활동을 제시하지 않았습니다.

| 지식 \ 인지 | 1. 기억 | 2. 이해 | 3. 적용 | 4. 분석 | 5. 평가 | 6. 창안 |
|---|---|---|---|---|---|---|
| **A. 사실적 지식** | `A1` — | `A2` • 세계 주요 종교의 기원과 창시자 연표 (02-01)<br>• 돌잔치·성년식·장례 속 통과 의례 정리 (03-01)<br>**성취기준:** 02-01, 03-01 | `A3` — | `A4` • 종교 문화유산을 건축·음악·미술·문학으로 분류 (03-03)<br>**성취기준:** 03-03 | `A5` — | `A6` — |
| **B. 개념적 지식** | `B1` — | `B2` • 종교의 의미와 역할 설명 (01-01)<br>• 종교별 세계관과 윤리 설명 (02-03)<br>• 종교가 말하는 공동선 설명 (04-02)<br>**성취기준:** 01-01, 02-03, 04-02 | `B3` • 종교적 지혜를 사회 문제에 적용 (01-03)<br>• 종교계의 사회 문제 해법을 지역 문제에 적용 (04-03)<br>**성취기준:** 01-03, 04-03 | `B4` • 종교별 경전·의례 비교 (02-02)<br>• 종교들의 공통 덕목 분석 (04-01)<br>**성취기준:** 02-02, 04-01 | `B5` • 종교 건축물의 아름다움 감상 (03-02)<br>• 유사 종교 판별 기준 평가 (04-04)<br>**성취기준:** 03-02, 04-04 | `B6` • 종교 문화유산을 융합 작품으로 표현 (03-04)<br>**성취기준:** 03-04 |
