# 영어Ⅰ 탐구활동 추천 매트릭스

2022 개정 교육과정 영어Ⅰ 성취기준 16개를 개정 블룸 분류 칸에 배치하고, 칸마다 과목에 맞춘 탐구활동을 정리했습니다. [전체 README로 돌아가기](../README.md)

## 성취기준 배치

주된 칸은 굵게 표시했습니다.

| 코드 | 성취기준 | 칸 |
|---|---|---|
| [12영Ⅰ-01-01] | 말이나 글의 세부 정보를 파악한다. | **A2** 사실적·이해 |
| [12영Ⅰ-01-02] | 말이나 글의 주제나 요지를 파악한다. | **B2** 개념적·이해 |
| [12영Ⅰ-01-03] | 화자나 필자의 심정이나 의도를 추론한다. | **B2** 개념적·이해 |
| [12영Ⅰ-01-04] | 말이나 글에서 일이나 사건의 논리적 관계를 파악한다. | **B4** 개념적·분석 |
| [12영Ⅰ-01-05] | 말이나 글의 맥락을 바탕으로 어구나 문장의 함축적 의미를 추론한다. | **B2** 개념적·이해 |
| [12영Ⅰ-01-06] | 말이나 글의 전개 방식이나 구조를 파악한다. | **B4** 개념적·분석 |
| [12영Ⅰ-01-07] | 적절한 전략을 활용하여 다양한 매체로 된 말이나 글의 의미를 파악한다. | **D3** 메타인지·적용 |
| [12영Ⅰ-01-08] | 우리 문화 및 타 문화의 다양한 관점에 대해 포용하고 공감하는 태도를 가진다. | **B4** 개념적·분석 |
| [12영Ⅰ-02-01] | 사실적 정보를 말이나 글로 설명한다. | **A2** 사실적·이해 |
| [12영Ⅰ-02-02] | 경험이나 계획 또는 일이나 사건을 말이나 글로 설명한다. | **A3** 사실적·적용 |
| [12영Ⅰ-02-03] | 상대방을 배려하고 존중하는 태도로 자신의 의견이나 감정을 표현한다. | **C6** 절차적·창안 |
| [12영Ⅰ-02-04] | 듣거나 읽은 내용을 말이나 글로 요약한다. | **B2** 개념적·이해 |
| [12영Ⅰ-02-05] | 서신, 신청서, 지원서 등의 서식을 목적에 맞게 작성한다. | **C3** 절차적·적용 |
| [12영Ⅰ-02-06] | 글의 구조나 내용 및 표현을 점검하고 쓰기 윤리를 준수하여 고쳐 쓴다. | **C5** 절차적·평가 |
| [12영Ⅰ-02-07] | 다양한 매체와 적절한 전략을 활용하여 정보를 창의적으로 전달한다. | **A6** 사실적·창안, D3 메타인지·적용 |
| [12영Ⅰ-02-08] | 협력적이고 능동적으로 말하기나 쓰기 과업을 수행한다. | **C3** 절차적·적용 |

## 과목별 활동 매트릭스

활동 뒤 괄호는 관련 성취기준 코드 뒷자리, 칸 끝의 “성취기준”은 그 칸에 배치된 성취기준입니다.

| 지식 \ 인지 | 1. 기억 | 2. 이해 | 3. 적용 | 4. 분석 | 5. 평가 | 6. 창안 |
|---|---|---|---|---|---|---|
| **A. 사실적 지식** | `A1` • 주제별 어휘와 담화 표지 목록 익히기 | `A2` • 세부 정보 찾기와 근거 문장 표시 (01-01)<br>• 조사한 사실 정보 영어로 설명 (02-01)<br>**성취기준:** 01-01, 02-01 | `A3` • 경험이나 사건을 시간 순서로 말하기 (02-02)<br>**성취기준:** 02-02 | `A4` • 지문 속 사실 문장과 의견 문장 구별 (01-08) | `A5` • 영어 기사 수치와 출처를 원자료와 대조 | `A6` • 다양한 매체로 정보를 창의적으로 전달하는 영어 카드뉴스 (02-07)<br>**성취기준:** 02-07 |
| **B. 개념적 지식** | `B1` • 담화 표지 기능 회상 (01-04) | `B2` • 주제·요지 파악과 함축 의미 추론 (01-02, 01-05)<br>• 필자 의도 추론 (01-03)<br>• 읽은 내용 요약 (02-04)<br>**성취기준:** 01-02, 01-03, 01-05, 02-04 | `B3` • 담화 표지를 단서로 이어질 내용 예측 (01-04) | `B4` • 글의 전개 방식 구조도 그리기 (01-06)<br>• 사건의 논리적 관계 연결 (01-04)<br>• 문화 간 관점 차이 비교 분석 (01-08)<br>**성취기준:** 01-04, 01-06, 01-08 | `B5` • 같은 주제의 두 글 설득력 비교 평가 | `B6` • 다른 문화권 인물 관점으로 다시 쓰기 (01-08) |
| **C. 절차적 지식** | `C1` • 서신·지원서 서식 구성 요소 회상 (02-05) | `C2` • 문단 구성 원리 설명 (01-06) | `C3` • 목적에 맞는 서신·지원서 작성 (02-05)<br>• 모둠 말하기·쓰기 과업 협력 수행 (02-08)<br>**성취기준:** 02-05, 02-08 | `C4` • 모범 글의 구조와 연결어 분석 (01-06) | `C5` • 구조·내용·표현 점검과 쓰기 윤리 지켜 고쳐 쓰기 (02-06)<br>**성취기준:** 02-06 | `C6` • 배려하는 태도로 의견 표현하는 에세이·스피치 (02-03)<br>**성취기준:** 02-03 |
| **D. 메타인지 지식** | `D1` • 나의 읽기·듣기 전략 목록 (01-07) | `D2` • 이해가 어려웠던 지문의 원인 설명 | `D3` • 매체에 맞는 이해 전략 적용 (01-07)<br>• 전달 전략 골라 발표 (02-07)<br>**성취기준:** 01-07, 02-07 | `D4` • 발표 녹화 회고 | `D5` • 말하기·쓰기 자기평가 루브릭 (02-06) | `D6` • 영어 학습 목표와 계획 |
