# 인간과 심리 탐구활동 추천 매트릭스

2022 개정 교육과정 인간과 심리 성취기준 15개를 개정 블룸 분류 칸에 배치하고, 칸마다 과목에 맞춘 탐구활동을 정리했습니다. [전체 README로 돌아가기](../README.md)

## 성취기준 배치

주된 칸은 굵게 표시했습니다.

| 코드 | 성취기준 | 칸 |
|---|---|---|
| [12심리01-01] | 과학으로서 현대 심리학의 목표와 특징을 이해하고 심리학에 대한 호기심을 갖는다. | **B2** 개념적·이해 |
| [12심리01-02] | 심리학에서 사용되는 주요 연구 방법의 장단점을 탐색하고 심리학 연구에서 과학적 가치와 윤리적 가치가 조화되는 것의 중요성을 인식한다. | **C4** 절차적·분석 |
| [12심리01-03] | 심리학 내 다양한 하위 분야가 실생활과 관련되거나 사회 발전에 기여한 사례를 탐색하고 자신의 진로 탐색과 연결한다. | **A4** 사실적·분석, D6 메타인지·창안 |
| [12심리02-01] | 뇌의 주요 구조와 심리적 기능의 관계, 경험⋅학습이 뇌 가소성에 미치는 영향을 탐구하여 행동의 생물학적 기초에 대한 새로운 시각을 갖는다. | **B2** 개념적·이해 |
| [12심리02-02] | 전 생애 발달 과정에서 청소년기의 특징⋅발달 과업을 이해하고 성찰함으로써 자기 수용 태도를 함양한다. | **D4** 메타인지·분석 |
| [12심리02-03] | 지각⋅기억⋅학습의 기본 원리에 대한 이해를 바탕으로 실생활에서의 오류를 인지하고 학습 효율을 높이는 방안을 실천하여 자기 효능감을 증진한다. | **B3** 개념적·적용, D3 메타인지·적용 |
| [12심리02-04] | 성격과 동기 차원에서 주요 개인차의 개념을 이해하고 올바른 자기 이해에 활용한다. | **D2** 메타인지·이해 |
| [12심리02-05] | 부정⋅긍정 정서의 종류와 기능을 탐색하고 실생활에서 효과적인 정서 조절 방법을 이해하고 실천한다. | **D3** 메타인지·적용 |
| [12심리03-01] | 상황적 요인이 개인의 태도 변화와 집단 내 상호 작용에 미치는 영향을 분석하고 타인에 대한 개방적 태도를 가진다. | **B4** 개념적·분석 |
| [12심리03-02] | 상황적 관점에서 사회 문제의 원인을 분석하고 창의적 해결 방안을 도출하여 실천한다. | **B4** 개념적·분석, B6 개념적·창안 |
| [12심리03-03] | 갈등적 관계를 촉진하거나 완화하는 요인을 탐색하고 적용함으로써 사회 통합을 위한 의사소통 능력과 공동체 의식을 기른다. | **B3** 개념적·적용 |
| [12심리03-04] | 협력적 관계의 형성과 발전에 기여하는 요인을 탐색하고 적용함으로써 타인을 배려하는 자세를 갖고 긍정적인 인간관계를 맺는 능력을 키운다. | **B3** 개념적·적용 |
| [12심리04-01] | 적응⋅부적응의 의미와 유형을 탐색하여 인간 적응의 역동성⋅다양성을 이해하고 정신장애에 대한 편견을 해소한다. | **B2** 개념적·이해 |
| [12심리04-02] | 삶의 변화에 따른 스트레스 발생과 건강의 관계를 이해하고 효과적인 스트레스 대처 방안을 적용하여 회복 탄력성을 기른다. | **D3** 메타인지·적용 |
| [12심리04-03] | 행복의 의미에 대한 탐색에 기초하여 자기 자신의 행복관을 정립하고 개인과 사회 수준에서 행복을 증진할 수 있는 방안을 탐색하고 실천한다. | **D5** 메타인지·평가, B6 개념적·창안 |

## 과목별 활동 매트릭스

활동 뒤 괄호는 관련 성취기준 코드 뒷자리, 칸 끝의 “성취기준”은 그 칸에 배치된 성취기준입니다. 성취기준이 없는 칸(—)은 이 과목의 교육목표에 해당하지 않아 활동을 제시하지 않았습니다.
