# 직무 의사소통 탐구활동 추천 매트릭스

2022 개정 교육과정 직무 의사소통 성취기준 10개를 개정 블룸 분류 칸에 배치하고, 칸마다 과목에 맞춘 탐구활동을 정리했습니다. [전체 README로 돌아가기](../README.md)

## 성취기준 배치

주된 칸은 굵게 표시했습니다.

| 코드 | 성취기준 | 칸 |
|---|---|---|
| [12직의01-01] | 직무 의사소통의 목적과 맥락, 매체, 참여자 특성을 이해하고 적절한 표현을 사용하여 능동적으로 소통한다. | **B2** 개념적·이해, B3 개념적·적용 |
| [12직의01-02] | 직무 공동체의 다양한 소통 문화와 직무 환경 변화에 적합하게 자기를 소개하고 면접에 참여한다. | **C3** 절차적·적용, C5 절차적·평가 |
| [12직의01-03] | 효과적인 진로 탐색 및 직무 수행을 위해 다양한 방법으로 정보를 수집하고 분석하여 내용을 이해하고 평가한다. | **A5** 사실적·평가, A3 사실적·적용 |
| [12직의01-04] | 적절한 매체를 사용하여 직무에 필요한 정보를 체계적으로 관리하고 활용한다. | **A4** 사실적·분석, A6 사실적·창안 |
| [12직의01-05] | 정보를 효과적으로 조직하여 직무의 목적⋅대상⋅상황에 적합하게 표현한다. | **C6** 절차적·창안, C2 절차적·이해 |
| [12직의01-06] | 직무 수행 과정에서 발생하는 의사소통 문제와 대인 관계 갈등에 대해 대화와 협의로 대처하고 조정한다. | **B3** 개념적·적용 |
| [12직의01-07] | 직무 공동체의 의사 결정 과정에 적극적으로 참여하여 대안을 탐색하고 합리적으로 문제를 해결한다. | **B6** 개념적·창안, B4 개념적·분석 |
| [12직의01-08] | 직무 상황에서 구성원들과 다양한 매체를 활용하여 적극적으로 협업하고 언어 예절을 갖추어 소통한다. | **C3** 절차적·적용, C4 절차적·분석 |
| [12직의01-09] | 개인의 권리와 정보 보안에 대한 책무를 인식하면서 직무 의사소통에 참여한다. | **D3** 메타인지·적용 |
| [12직의01-10] | 직무 환경의 변화에 대응하여 지속적으로 자기를 계발하고, 직무 의사소통에 능동적이고 협력적으로 참여하는 태도를 지닌다. | **D6** 메타인지·창안 |

## 과목별 활동 매트릭스

활동 뒤 괄호는 관련 성취기준 코드 뒷자리, 칸 끝의 “성취기준”은 그 칸에 배치된 성취기준입니다. 성취기준이 없는 칸(—)은 이 과목의 교육목표에 해당하지 않아 활동을 제시하지 않았습니다.
